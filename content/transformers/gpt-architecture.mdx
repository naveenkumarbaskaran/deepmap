## Decoder-Only Transformers

GPT (Generative Pre-trained Transformer) uses a **decoder-only** architecture: a stack of transformer blocks, each with causal (left-to-right) self-attention. There is no encoder, no cross-attention, and no bidirectional context. Each token can only attend to tokens at earlier positions (including itself).

This is enforced by a **causal attention mask** — a lower-triangular mask that zeroes out attention weights to future positions. During training, the entire sequence is processed in one forward pass: position i predicts token i+1 using only tokens 0…i.

## Autoregressive Language Modeling

Pre-training objective: maximize the log probability of each token given its left context:

```
L = Σ log P(token_i | token_0, ..., token_{i-1})
```

This is the simplest possible objective — predict the next word — and yet it scales to emergent capabilities including few-shot reasoning, code generation, and instruction following. The "emergent" nature means these capabilities appear abruptly above certain scale thresholds and are not explicitly trained for.

Each generation showed qualitative jumps in capability — few-shot prompting emerged at GPT-3 scale.

## KV-Cache for Efficient Inference

During inference, autoregressive generation is token-by-token. At each step, attention must attend to all previous tokens. Without optimization, this requires recomputing keys and values for all past tokens on every step — O(n²) work per token, O(n³) total.

The **KV-cache** saves Key and Value tensors for all past positions. At each new step, only the new token's Q/K/V are computed; Keys and Values are retrieved from cache. This reduces generation cost from O(n³) to O(n²) in total, with a memory footprint of `2 × n × n_layers × d_model × dtype_bytes`.

## The Decoder-Only Trend

After GPT-3, the field largely converged on decoder-only architectures even for tasks previously dominated by encoder-decoder models (translation, summarization). Reasons:

- Simpler: one pre-training objective, one architecture variant
- Scales better: emergent few-shot learning means no fine-tuning needed for many tasks
- Generative: naturally handles open-ended generation that encoder models cannot

## Implementing Causal Masking in NumPy

```python runnable
import numpy as np

np.random.seed(42)
n, d_model, d_k = 5, 8, 8

X = np.random.randn(n, d_model)
W_Q = np.random.randn(d_model, d_k) * 0.1
W_K = np.random.randn(d_model, d_k) * 0.1
W_V = np.random.randn(d_model, d_k) * 0.1

Q = X @ W_Q; K = X @ W_K; V = X @ W_V
scores = Q @ K.T / np.sqrt(d_k)

print("Uncaused (bidirectional) attention scores:")
print(np.round(scores, 2))

# Causal mask: upper triangle = -inf, lower triangle = 0
causal_mask = np.triu(np.ones((n, n)), k=1)   # 1s above diagonal
causal_mask_logit = causal_mask * -1e9         # replace 1s with -inf

print("\\nCausal mask (positions blocked = -1e9):")
print(causal_mask_logit.astype(int))

masked_scores = scores + causal_mask_logit
print("\\nMasked scores (future = -1e9):")
print(np.round(masked_scores, 2))

def softmax(x):
    e = np.exp(x - x.max(axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)

attn_weights = softmax(masked_scores)
print("\\nCausal attention weights (upper triangle ≈ 0):")
print(np.round(attn_weights, 3))

# Demonstrate: token 0 can only see itself; token 4 can see all 5
print("\\nToken 0 weights (should attend only to pos 0):", attn_weights[0])
print("Token 4 weights (can attend to all):", np.round(attn_weights[4], 3))
```
