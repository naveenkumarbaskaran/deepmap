## Treating Images as Sequences

Convolutional networks impose an inductive bias: local spatial features, translation equivariance. Transformers have no such bias — they learn relationships from scratch. The key question was: how do you feed an image into an architecture designed for token sequences?

**ViT (Dosovitskiy et al., 2020)** answers by splitting the image into fixed-size patches and treating each patch as a token. A 224×224 image with 16×16 patches produces 196 tokens — well within transformer sequence length limits.

## Patch Embedding

Each patch (H_p × W_p × C, where C = 3 for RGB) is flattened into a vector of length `H_p × W_p × C`, then linearly projected to d_model via a learned embedding matrix:

```
z_i = Flatten(patch_i) · W_E + b_E
```

This is equivalent to a single convolutional layer with kernel size = stride = patch size, and output channels = d_model. The result is a sequence of `N = (H/H_p) × (W/W_p)` patch embeddings.

## The [CLS] Token

A special learnable `[CLS]` token is prepended to the patch sequence, bringing the total sequence length to N+1. After passing through the transformer stack, the `[CLS]` token's output representation is used as the global image representation for classification — mirroring BERT's `[CLS]` for sentence classification.

## Positional Embeddings for Patches

Standard 1D learned positional embeddings are added to the patch embeddings. While patches have inherent 2D structure, the original ViT paper found that 1D positional embeddings (treating patch index as position) worked well in practice, with the attention heads learning to interpret 2D proximity implicitly.

## ViT vs. CNN Trade-offs

| Aspect | CNN | ViT |
|--------|-----|-----|
| Inductive bias | Strong (locality, equivariance) | Weak (learns from data) |
| Data efficiency | Good (10k–100k images) | Poor (needs millions) |
| Scale behavior | Plateaus | Keeps improving with scale |
| Receptive field | Local by design | Global from layer 1 |

ViT outperforms CNNs at scale (pre-trained on JFT-300M or ImageNet-21k) but underperforms on small datasets.

## Hierarchical Variants

**DeiT** (Touvron et al., 2021): ViT trained on ImageNet-1k alone via knowledge distillation from a CNN teacher. Closes the data-efficiency gap significantly.

**Swin Transformer** (Liu et al., 2021): Introduces shifted-window attention — attention is computed within local windows (7×7 patches), and windows shift between layers. This gives O(n) complexity vs ViT's O(n²) and produces hierarchical feature maps usable as a CNN backbone for detection and segmentation.

## Patch Tokenization in NumPy

```python runnable
import numpy as np

np.random.seed(5)

# Simulate a 32×32 RGB image
H, W, C = 32, 32, 3
image = np.random.randint(0, 256, (H, W, C)).astype(np.float32) / 255.0
print("Image shape:", image.shape)

# Patch size: 8×8 (produces 4×4 = 16 patches)
P = 8
n_h, n_w = H // P, W // P      # 4, 4
N = n_h * n_w                  # 16 patches total
d_patch = P * P * C            # 192-dim flattened patch
d_model = 64                   # projection dimension

print(f"Patch grid: {n_h}×{n_w} = {N} patches")
print(f"Flattened patch dim: {P}×{P}×{C} = {d_patch}")

# Extract and flatten patches
patches = []
for i in range(n_h):
    for j in range(n_w):
        patch = image[i*P:(i+1)*P, j*P:(j+1)*P, :]  # (P, P, C)
        patches.append(patch.flatten())               # (d_patch,)
patches = np.stack(patches)  # (N, d_patch)
print("\\nAll patches shape:", patches.shape)

# Linear patch embedding: project to d_model
W_E = np.random.randn(d_patch, d_model) * 0.01   # learned projection
patch_embeddings = patches @ W_E                   # (N, d_model)
print("Patch embeddings shape:", patch_embeddings.shape)

# Prepend [CLS] token (learned in practice, random here)
cls_token = np.random.randn(1, d_model) * 0.01
tokens = np.concatenate([cls_token, patch_embeddings], axis=0)  # (N+1, d_model)
print("Token sequence (with [CLS]):", tokens.shape)

# Add 1D positional embeddings
pos_embed = np.random.randn(N+1, d_model) * 0.01
tokens = tokens + pos_embed
print("After positional embedding:", tokens.shape)
print("\\n[CLS] token (position 0):", np.round(tokens[0, :8], 4), "...")
print("Patch 1 token (position 1):", np.round(tokens[1, :8], 4), "...")
```
