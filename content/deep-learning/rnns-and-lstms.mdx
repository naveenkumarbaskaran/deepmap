## Processing Sequences

Feedforward networks assume inputs are independent. Language, audio, and time-series data are not — the word "bank" means something different after "river" vs. "deposit". Recurrent Neural Networks (RNNs) handle this by maintaining a **hidden state** `h_t` that acts as a memory, updated at each timestep using both the current input `x_t` and the previous hidden state `h_{t-1}`.

The vanilla RNN update is simply:

```
h_t = tanh(W_h · h_{t-1} + W_x · x_t + b)
```

The same weight matrices `W_h` and `W_x` are reused at every timestep — analogous to weight sharing in CNNs.

## The Vanishing Gradient Problem

Training RNNs via backpropagation through time (BPTT) requires multiplying gradients across every timestep. If the dominant eigenvalue of `W_h` is less than 1, gradients shrink exponentially with sequence length. After 20–30 timesteps, the gradient signal from early inputs is essentially zero — the network cannot learn long-range dependencies like matching a subject to its verb 50 tokens later.

## LSTM: Long Short-Term Memory

LSTMs (Hochreiter & Schmidhuber, 1997) add a separate **cell state** `C_t` — a highway for gradient flow — and three **gates** that control information:

| Gate | Role |
|------|------|
| **Forget gate** `f_t` | What fraction of the old cell state to erase |
| **Input gate** `i_t` | What new information to write to the cell state |
| **Output gate** `o_t` | What part of the cell state to expose as hidden state |

Each gate is a sigmoid in [0, 1], acting as a soft on/off switch. Because the cell state is updated additively (`C_t = f_t * C_{t-1} + i_t * C̃_t`), gradients can flow backwards without shrinking — solving vanishing gradients for practical sequence lengths.

## GRU: A Simpler Alternative

The Gated Recurrent Unit (GRU, 2014) merges the cell and hidden state and uses only two gates (reset and update). It is computationally cheaper than an LSTM and performs comparably on many tasks.

## Bidirectional RNNs

A standard RNN only uses past context. A **bidirectional RNN** runs one RNN forward and another backward, then concatenates both hidden states. This gives each position access to full left and right context — essential for tasks like named entity recognition.

## Vanilla RNN Forward Pass

```python runnable
import numpy as np

np.random.seed(42)

# Dimensions
input_size = 4
hidden_size = 3
seq_len = 5

# Random weights (small init)
Wx = np.random.randn(hidden_size, input_size) * 0.1
Wh = np.random.randn(hidden_size, hidden_size) * 0.1
b  = np.zeros(hidden_size)

# Random input sequence: 5 timesteps, each a 4-dim vector
X = np.random.randn(seq_len, input_size)

# Forward pass
h = np.zeros(hidden_size)   # initial hidden state
print(f"Initial hidden state: {np.round(h, 4)}")
print()

for t in range(seq_len):
    h = np.tanh(Wh @ h + Wx @ X[t] + b)
    print(f"t={t+1}  input={np.round(X[t], 3)}  ->  h={np.round(h, 4)}")

print()
print("Final hidden state encodes the entire sequence:")
print(np.round(h, 4))
```
