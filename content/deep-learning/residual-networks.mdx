## The Degradation Problem

A naive assumption: adding more layers should help — a deeper network can at worst learn identity mappings for the extra layers. In practice, optimizing very deep networks is hard. Beyond ~20 layers, accuracy saturates and then **degrades** even on the training set. This is not overfitting — it is an optimization problem. The network fails to learn the identity function through stacked non-linear layers.

## The Residual Connection

He et al. (2015) introduced a simple fix: instead of learning a mapping `H(x)` directly, learn the **residual** `F(x) = H(x) − x` and add the input back:

```
output = F(x, {W}) + x
```

The `+ x` is a **skip connection** (also called a shortcut). If the optimal transformation is close to identity, the network just needs `F(x) ≈ 0` — much easier to learn than `H(x) ≈ x` from scratch.

## Why Skip Connections Help Gradient Flow

During backpropagation, the gradient through a residual block is:

```
∂loss/∂x = ∂loss/∂output · (∂F/∂x + 1)
```

The `+1` term ensures the gradient is never completely zeroed by the learned branch `F`. Even if `∂F/∂x ≈ 0`, the gradient highway through the skip connection keeps the signal alive — allowing effective training of 50, 100, or even 1,000+ layer networks.

## Bottleneck Blocks

For deeper ResNets (ResNet-50 and above), a 3-layer **bottleneck block** replaces the 2-layer basic block:

1. `1×1 conv` — reduce channels (e.g., 256 → 64)
2. `3×3 conv` — learn spatial features at reduced cost
3. `1×1 conv` — restore channels (64 → 256)

The 1×1 convolutions act as channel-wise projections, cutting computation by ~4× while keeping the receptive field the same.

## Related Architectures

**Highway Networks** (2015) used learned gating on the skip connection (like LSTM gates). ResNets simplified this to a fixed, unweighted addition — and worked better in practice.

**DenseNet** (2017) extends the idea: every layer is connected to every subsequent layer, concatenating (not adding) feature maps. This maximizes gradient flow and feature reuse but increases memory.

## Residual Block Forward Pass

```python runnable
import numpy as np

def relu(x):
    return np.maximum(0, x)

def batch_norm_simple(x):
    """Simplified batch norm: zero-mean, unit variance."""
    return (x - x.mean()) / (x.std() + 1e-8)

def residual_block(x, W1, W2):
    """
    Basic ResNet residual block:
      F(x) = W2 * relu(BN(W1 * x))
      output = relu(F(x) + x)
    """
    # First conv (simulated as matrix multiply for 1D vectors)
    out = relu(batch_norm_simple(W1 @ x))
    # Second conv
    out = batch_norm_simple(W2 @ out)
    # Skip connection: add input to residual
    out = relu(out + x)
    return out

np.random.seed(3)
dim = 8   # feature dimension

# Two weight matrices (simulating conv filters)
W1 = np.random.randn(dim, dim) * 0.1
W2 = np.random.randn(dim, dim) * 0.1

x = np.random.randn(dim)

print("Input x:")
print(np.round(x, 3))

F_x = relu(batch_norm_simple(W1 @ x))
F_x = batch_norm_simple(W2 @ F_x)
print("\\nResidual F(x) (what the block must learn):")
print(np.round(F_x, 3))

output = relu(F_x + x)
print("\\nOutput F(x) + x (skip connection applied):")
print(np.round(output, 3))

# Demonstrate gradient highway
print("\\n--- Gradient check ---")
grad_output = np.ones(dim)
# Gradient through skip branch = 1 (identity, unaffected by F)
grad_skip = grad_output.copy()
print(f"Gradient via skip connection (always 1 per unit): {np.round(grad_skip, 3)}")
print("This persists regardless of W1/W2 values -> no vanishing gradient.")
```
