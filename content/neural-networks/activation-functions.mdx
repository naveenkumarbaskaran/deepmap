## Why Nonlinearity?

Without activation functions, stacking layers is pointless. The composition of linear maps is still linear: W₂(W₁x) = (W₂W₁)x, which collapses to a single matrix multiply. Nonlinear activations break this — each layer genuinely learns a new representation.

The choice of activation shapes training dynamics: how fast gradients flow, whether neurons "die", and how well the model scales to depth.

## Sigmoid and Tanh — The Classics

**Sigmoid** σ(x) = 1/(1+e⁻ˣ) squashes all inputs to (0, 1). It was the default in early networks, but has two problems:

- **Vanishing gradients**: the gradient σ′(x) = σ(x)(1−σ(x)) peaks at 0.25 and decays exponentially away from zero. After 10 layers, gradients become numerically zero.
- **Non-zero centred**: outputs are always positive, so weight gradients all share the same sign — slowing convergence.

**Tanh** maps to (−1, 1) and is zero-centred, fixing the sign issue. But it still saturates at large |x|, so the vanishing gradient problem remains.

Both functions are still used in specific roles: sigmoid for binary classification outputs, tanh inside LSTMs.

## ReLU and Its Variants

**ReLU** (Rectified Linear Unit): f(x) = max(0, x)

ReLU is fast to compute, does not saturate for positive inputs, and empirically trains deep networks much better than sigmoid or tanh. The gradient is 1 for x > 0 and 0 for x ≤ 0 — clean and stable.

**Dying ReLU problem**: if a neuron's pre-activation is always negative (e.g. due to a large negative bias), the gradient is permanently zero — the neuron never updates. Mitigations:

- **Leaky ReLU**: f(x) = x if x > 0 else αx (typically α = 0.01). Keeps a small gradient for negative inputs.
- **ELU** (Exponential Linear Unit): f(x) = x if x > 0 else α(eˣ−1). Smooth at zero, negative saturation gives robustness to noise.

## GELU — The Transformer Standard

**GELU** (Gaussian Error Linear Unit): f(x) = x · Φ(x), where Φ is the standard normal CDF.

Intuitively, GELU stochastically gates inputs — small values are more likely to be zeroed. The result is a smooth, differentiable curve that resembles ReLU but has non-zero gradients for small negatives. This smoothness aids optimisation in deep models. GELU is used in BERT, GPT, and most modern transformers.

## Softmax — For Probability Outputs

Softmax converts a vector of raw logits into a probability distribution:

softmax(z)ᵢ = exp(zᵢ) / Σⱼ exp(zⱼ)

It is used in the output layer for multi-class classification. All outputs are positive and sum to 1. Numerically, subtract the max logit before exponentiating to avoid overflow.

## Code: Activation Values at a Glance

```python runnable
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def tanh(x):
    return np.tanh(x)

def relu(x):
    return np.maximum(0, x)

def leaky_relu(x, alpha=0.01):
    return np.where(x > 0, x, alpha * x)

def gelu(x):
    # Exact GELU via error function approximation
    return 0.5 * x * (1 + np.tanh(np.sqrt(2 / np.pi) * (x + 0.044715 * x**3)))

def softmax(x):
    e = np.exp(x - np.max(x))   # numerically stable
    return e / e.sum()

xs = np.array([-2.0, -1.0, 0.0, 1.0, 2.0])

print(f"{'x':>6}  {'sigmoid':>8}  {'tanh':>8}  {'relu':>6}  {'leaky':>8}  {'gelu':>8}")
print("-" * 60)
for x in xs:
    print(f"{x:>6.1f}  {sigmoid(x):>8.4f}  {tanh(x):>8.4f}  "
          f"{relu(x):>6.4f}  {leaky_relu(x):>8.4f}  {gelu(x):>8.4f}")

# Gradient of sigmoid — shows vanishing gradient
print("\\nSigmoid gradients (peak = 0.25 at x=0):")
grads = sigmoid(xs) * (1 - sigmoid(xs))
for x, g in zip(xs, grads):
    bar = "█" * int(g * 40)
    print(f"  x={x:+.0f}  grad={g:.4f}  {bar}")

# Softmax on logits
logits = np.array([2.0, 1.0, 0.5, -1.0])
probs  = softmax(logits)
print(f"\\nSoftmax([2.0, 1.0, 0.5, -1.0]) = {probs.round(4)}  sum={probs.sum():.4f}")
```
