## What is Backpropagation?

Backpropagation is the algorithm that teaches neural networks. It computes how much each weight in the network contributed to the final error — then adjusts them all to reduce that error. Without backprop, training deep networks would be computationally intractable.

The key insight: **the chain rule of calculus lets us efficiently compute gradients for every parameter in the network in a single backward pass.**

## How it works

1. **Forward pass** — feed input through the network, compute output $\hat{y}$
2. **Compute loss** — measure how wrong the prediction was: $L = \frac{1}{2}(y - \hat{y})^2$
3. **Backward pass** — apply the chain rule layer by layer, computing $\frac{\partial L}{\partial w}$ for every weight $w$
4. **Update weights** — $w \leftarrow w - \eta \cdot \frac{\partial L}{\partial w}$ where $\eta$ is the learning rate

The chain rule is the engine:

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} \cdot \frac{\partial z}{\partial w}$$

Each term is easy to compute individually. Backprop just chains them together efficiently.

## In code

<CodeRunner code={`import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_deriv(x):
    s = sigmoid(x)
    return s * (1 - s)

# Simple 1-layer network
x = np.array([0.5, 0.8])    # input
y = 1.0                       # target
w = np.array([0.3, -0.1])    # weights

# Forward pass
z = np.dot(w, x)
y_hat = sigmoid(z)
loss = 0.5 * (y - y_hat) ** 2

# Backward pass
dL_dyhat = -(y - y_hat)
dyhat_dz = sigmoid_deriv(z)
dz_dw = x

# Chain rule
grad_w = dL_dyhat * dyhat_dz * dz_dw

print(f"Prediction: {y_hat:.4f}")
print(f"Loss:       {loss:.4f}")
print(f"Gradients:  {grad_w}")
print(f"Updated w:  {w - 0.1 * grad_w}")
`} />
