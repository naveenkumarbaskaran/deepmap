## Why Matrix Calculus?

Scalar calculus gives you $\frac{d}{dx} f(x)$. Neural networks work with matrices and vectors — weights $W$, activations $\mathbf{a}$, losses $L$. When you compute the gradient $\frac{\partial L}{\partial W}$, you're doing matrix calculus. Understanding it means you can derive backpropagation from first principles, debug gradient explosions, and implement custom layers correctly.

## The Layout Convention

Before anything, fix your convention: when differentiating a scalar $f$ with respect to a column vector $\mathbf{x} \in \mathbb{R}^n$, the gradient $\frac{\partial f}{\partial \mathbf{x}}$ is a column vector of the same shape as $\mathbf{x}$. This is the **denominator layout** (also called Jacobian layout). NumPy and PyTorch use this convention.

## Derivative of a Linear Form

The simplest case: $f(\mathbf{x}) = \mathbf{w}^\top \mathbf{x}$ (dot product, a scalar).

$$\frac{\partial (\mathbf{w}^\top \mathbf{x})}{\partial \mathbf{x}} = \mathbf{w}$$

Intuition: $\mathbf{w}^\top \mathbf{x} = \sum_i w_i x_i$. The partial with respect to $x_i$ is $w_i$. Stack them into a vector: you get $\mathbf{w}$.

## Derivative of a Matrix-Vector Product

For $\mathbf{y} = W\mathbf{x}$ where $W \in \mathbb{R}^{m \times n}$, $\mathbf{x} \in \mathbb{R}^n$, $\mathbf{y} \in \mathbb{R}^m$:

$$\frac{\partial \mathbf{y}}{\partial \mathbf{x}} = W \qquad \text{(Jacobian: } m \times n \text{ matrix)}$$

If we have a scalar loss $L = f(\mathbf{y})$ and use the chain rule:

$$\frac{\partial L}{\partial \mathbf{x}} = W^\top \cdot \frac{\partial L}{\partial \mathbf{y}}$$

This is exactly why the backward pass through a linear layer multiplies the upstream gradient by $W^\top$.

## Gradient with Respect to the Weight Matrix

For $\mathbf{y} = W\mathbf{x}$, the gradient of a scalar loss $L$ with respect to $W$:

$$\frac{\partial L}{\partial W} = \frac{\partial L}{\partial \mathbf{y}} \cdot \mathbf{x}^\top$$

This is an outer product — a rank-1 matrix. For a mini-batch, this sums over examples. This formula is the core of backpropagation through any linear layer.

## Quadratic Forms

For $f(\mathbf{x}) = \mathbf{x}^\top A \mathbf{x}$ where $A$ is symmetric:

$$\frac{\partial f}{\partial \mathbf{x}} = 2A\mathbf{x}$$

For non-symmetric $A$: $\frac{\partial (\mathbf{x}^\top A \mathbf{x})}{\partial \mathbf{x}} = (A + A^\top)\mathbf{x}$. When $A = I$ this gives $2\mathbf{x}$, and you recover the gradient of L2 norm squared.

## The Jacobian Matrix

For a vector-valued function $f: \mathbb{R}^n \to \mathbb{R}^m$, the **Jacobian** is:

$$J = \frac{\partial f}{\partial \mathbf{x}} \in \mathbb{R}^{m \times n} \qquad \text{where } J_{ij} = \frac{\partial f_i}{\partial x_j}$$

The Jacobian of a softmax layer is non-trivial because outputs are coupled (they sum to 1). Computing it correctly is essential for the backward pass through softmax.

## Chain Rule in Matrix Form

For composed functions $L = f(g(\mathbf{x}))$:

$$\frac{\partial L}{\partial \mathbf{x}} = \left(\frac{\partial g}{\partial \mathbf{x}}\right)^\top \cdot \frac{\partial L}{\partial g}$$

Each layer in a network contributes a Jacobian factor. Backpropagation is the efficient left-to-right application of this product using the already-computed upstream gradients.

```python runnable
import numpy as np

rng = np.random.default_rng(7)

# --- Linear layer: forward + backward by hand ---
batch, n_in, n_out = 4, 3, 2
X = rng.normal(0, 1, (batch, n_in))    # (B, n_in)
W = rng.normal(0, 1, (n_in, n_out))    # (n_in, n_out)
b = np.zeros(n_out)

# Forward pass
Y = X @ W + b          # (B, n_out)

# Fake upstream gradient (dL/dY from next layer)
dL_dY = rng.normal(0, 1, Y.shape)   # (B, n_out)

# Backward pass — matrix calculus
dL_dW = X.T @ dL_dY          # (n_in, n_out)
dL_db = dL_dY.sum(axis=0)    # (n_out,)
dL_dX = dL_dY @ W.T          # (B, n_in)

print("Shapes:")
print(f"  X:      {X.shape}")
print(f"  W:      {W.shape}")
print(f"  Y=XW+b: {Y.shape}")
print(f"  dL/dW:  {dL_dW.shape}  (outer product, summed over batch)")
print(f"  dL/dX:  {dL_dX.shape}  (W.T @ upstream gradient)")

# --- Verify with numerical gradients ---
def loss(W_flat):
    W_ = W_flat.reshape(n_in, n_out)
    Y_ = X @ W_ + b
    return (Y_ * dL_dY).sum()   # linear loss for clean comparison

h = 1e-5
grad_numerical = np.zeros_like(W)
for i in range(n_in):
    for j in range(n_out):
        dw = np.zeros_like(W); dw[i, j] = h
        grad_numerical[i, j] = (loss((W+dw).ravel()) - loss((W-dw).ravel())) / (2*h)

print(f"\nAnalytic vs numerical gradient match: "
      f"{np.allclose(dL_dW, grad_numerical, atol=1e-5)}")
print(f"Max absolute error: {np.abs(dL_dW - grad_numerical).max():.2e}")
```
