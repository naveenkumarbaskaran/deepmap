## Why Bayesian Inference?

Standard ML gives you a point estimate: "the best weights are $W^*$." Bayesian inference gives you a *distribution over weights*: "here's how confident we are about the weights." This distinction matters enormously in safety-critical applications. A self-driving car should not just predict "stop sign" — it should know *how certain* it is. Bayesian methods provide the machinery for principled uncertainty quantification.

## Bayes Theorem in Depth

$$P(\theta \mid D) = \frac{P(D \mid \theta) \cdot P(\theta)}{P(D)}$$

Each term has a precise role:

| Term | Name | Role |
|------|------|------|
| $P(\theta \mid D)$ | Posterior | Belief about $\theta$ after seeing data $D$ |
| $P(D \mid \theta)$ | Likelihood | How well $\theta$ explains the data |
| $P(\theta)$ | Prior | Belief about $\theta$ before any data |
| $P(D)$ | Evidence (marginal) | Normalizing constant: $\int P(D\mid\theta)P(\theta)\,d\theta$ |

The evidence $P(D)$ is often intractable — it requires integrating over all possible parameter values. This is the central challenge of Bayesian inference and motivates approximate methods.

## Sequential Updating

Bayesian inference is naturally sequential. Start with a prior, observe data, compute the posterior. Then treat that posterior as the new prior for the next batch of data. This makes Bayesian models well-suited to online learning and continual learning — the model never "forgets" that its uncertainty should grow in distribution-shifted regions.

## Conjugate Priors

A **conjugate prior** is one where the posterior has the same functional form as the prior. This avoids intractable integrals.

The classic example: **Beta-Binomial conjugacy**.
- Prior: $\theta \sim \text{Beta}(\alpha, \beta)$
- Likelihood: $k$ heads in $n$ flips $\sim \text{Binomial}(n, \theta)$
- Posterior: $\theta \mid \text{data} \sim \text{Beta}(\alpha + k,\ \beta + n - k)$

The Beta distribution is parameterized by pseudocounts: $\alpha$ is "prior heads", $\beta$ is "prior tails". Observing real data just increments these counts. No integration needed.

Other key conjugate pairs used in ML:
- Gaussian prior + Gaussian likelihood → Gaussian posterior (Bayesian linear regression)
- Dirichlet prior + Categorical likelihood → Dirichlet posterior (topic models, LDA)

## MCMC: When Conjugacy Fails

For complex models (deep networks, hierarchical models), there's no closed-form posterior. **Markov Chain Monte Carlo (MCMC)** methods sample from the posterior by constructing a Markov chain that has the posterior as its stationary distribution.

The key idea: even if you can't integrate $P(D|\theta)P(\theta)$, you can *evaluate* it pointwise. MCMC uses these evaluations to propose and accept/reject steps, gradually exploring regions of high posterior probability.

Practical variants: Metropolis-Hastings, Hamiltonian Monte Carlo (HMC), No-U-Turn Sampler (NUTS) — used in Stan and PyMC.

## Bayesian Neural Networks

A **Bayesian Neural Network (BNN)** places a prior over all weights and infers a posterior $P(W \mid D)$. Predictions are made by integrating over the weight posterior — model averaging over infinitely many networks.

In practice: exact inference is intractable for large nets. Approximations include:
- **Variational inference**: approximate posterior $q(W) \approx P(W|D)$ by minimizing $KL(q \,\|\, P(W|D))$
- **MC Dropout**: treat dropout as approximate Bayesian inference; run multiple stochastic forward passes at test time
- **Deep Ensembles**: train $N$ networks from different initializations; empirically rivals full Bayesian inference

## Uncertainty Quantification

BNNs distinguish two kinds of uncertainty:
- **Aleatoric uncertainty**: irreducible noise in the data (measurement error)
- **Epistemic uncertainty**: uncertainty from insufficient data — reduces as more data is observed

This distinction is essential for safety-critical ML: a model should flag epistemic uncertainty on out-of-distribution inputs rather than confidently extrapolating.

```python runnable
import numpy as np

rng = np.random.default_rng(42)

# ===  Bayesian coin flip with Beta-Binomial conjugacy ===
# Prior: Beta(alpha, beta) — start with weak prior (1 pseudocount each)
alpha_prior, beta_prior = 1.0, 1.0

# Generate coin flips (true bias = 0.65)
true_p = 0.65
n_flips = 50
flips = rng.binomial(1, true_p, n_flips)   # 1=heads, 0=tails

print("=== Sequential Bayesian Updating ===")
print(f"True coin bias: {true_p}")
print(f"{'Flips seen':>10} | {'Heads':>6} | {'Posterior mean':>14} | {'95% CI'}")
print("-" * 55)

alpha, beta = alpha_prior, beta_prior
for n in [1, 5, 10, 20, 50]:
    heads = flips[:n].sum()
    tails = n - heads
    alpha_post = alpha_prior + heads
    beta_post  = beta_prior  + tails
    
    # Posterior is Beta(alpha_post, beta_post)
    post_mean = alpha_post / (alpha_post + beta_post)
    
    # 95% CI via quantiles of Beta distribution
    p_grid = np.linspace(0, 1, 10000)
    # Beta PDF (unnormalized: p^(a-1) * (1-p)^(b-1))
    pdf = p_grid**(alpha_post-1) * (1-p_grid)**(beta_post-1)
    pdf /= pdf.sum()
    cdf = np.cumsum(pdf)
    lo = p_grid[np.searchsorted(cdf, 0.025)]
    hi = p_grid[np.searchsorted(cdf, 0.975)]
    
    print(f"{n:>10} | {heads:>6} | {post_mean:>14.3f} | [{lo:.2f}, {hi:.2f}]")

# MC Dropout: epistemic uncertainty demo
print("\n=== MC Dropout Uncertainty (simulated) ===")
# Simulate 20 stochastic forward passes
true_logit = 1.5   # confident prediction
n_passes = 20
noise_scale = 0.8  # dropout noise

logits = rng.normal(true_logit, noise_scale, n_passes)
probs  = 1 / (1 + np.exp(-logits))   # sigmoid
print(f"Predicted probability: mean={probs.mean():.3f}, std={probs.std():.3f}")
print(f"Epistemic uncertainty (std): {probs.std():.3f}")
```
