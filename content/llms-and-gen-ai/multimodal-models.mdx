## Beyond Text: Why Multimodality?

Language alone captures only part of human communication. Images, audio, and video carry information that is expensive or impossible to describe purely in words. Multimodal models learn representations that span modalities — enabling tasks like image captioning, visual question answering, document understanding, and cross-modal generation.

## CLIP: Contrastive Image-Text Pre-Training

CLIP (Radford et al., OpenAI 2021) is the foundational approach to aligning vision and language representations. It trains an image encoder and a text encoder jointly using a **contrastive objective** on 400M (image, caption) pairs from the web:

- For a batch of N pairs, the goal is to maximize cosine similarity between the N matching image-text pairs while minimizing similarity for the N²−N non-matching pairs.
- The loss is a symmetric cross-entropy over similarity matrices.

CLIP learns a shared embedding space where "a photo of a dog" is close to dog images. This enables zero-shot classification: embed candidate class names as text, embed the image, pick the closest text.

## Vision-Language Models: LLaVA and GPT-4V

CLIP gives aligned embeddings, but not generation. Modern VLMs attach a visual encoder to a large language model:

1. **Vision encoder** (e.g., CLIP ViT-L/14) processes the image into patch embeddings.
2. **Projection layer** (linear or MLP) maps visual embeddings into the LLM's token embedding space.
3. **LLM** (e.g., LLaMA, Vicuna, GPT-4) autoregressively generates text conditioned on the projected image tokens and the text prompt.

**LLaVA** (Liu et al., 2023) demonstrated this architecture is surprisingly effective even with a simple linear projection, trained on instruction-following data with image+text pairs.

**GPT-4V** extends this to production quality with richer training data and a larger vision encoder.

## Image Tokenization vs Continuous Embeddings

There are two philosophies for representing images in LLMs:

**Continuous embeddings**: pass image patch features (from a ViT) directly as a sequence of continuous vectors alongside text token embeddings. The LLM attends over them with cross-attention or by concatenation. Used by LLaVA, Flamingo, GPT-4V.

**Discrete tokens**: quantize image patches into discrete codebook entries (e.g., with a VQ-VAE), treating them as tokens. Enables the same autoregressive next-token loss for images and text in a unified model. Used by early models like DALL-E 1, Chameleon.

## Cross-Attention for Modality Fusion

In models like **Flamingo** (DeepMind, 2022), visual features are injected into the LLM through **cross-attention layers** inserted between self-attention blocks. The text attends to visual features at every layer, enabling deep fusion rather than a one-time projection at input.

## Audio Models: Whisper

**Whisper** (OpenAI, 2022) is a transformer encoder-decoder trained on 680K hours of audio-transcript pairs. The encoder processes log-mel spectrograms; the decoder generates text tokens autoregressively. This enables robust automatic speech recognition (ASR) across languages and accents.

## Multimodal Generation: DALL-E 3 and Gemini

**DALL-E 3** uses a diffusion model conditioned on dense image captions generated by a captioner trained to be highly detailed. The key insight: better text descriptions lead to better text-image alignment.

**Gemini** (Google, 2023) is natively multimodal — trained from scratch on interleaved image, text, audio, and video tokens, rather than bolting a vision encoder onto a text LLM.

## CLIP Contrastive Loss — NumPy Implementation

```python runnable
import numpy as np

def clip_contrastive_loss(image_embeddings, text_embeddings, temperature=0.07):
    """
    Symmetric CLIP contrastive loss.
    
    image_embeddings: (N, D) — L2-normalised image features
    text_embeddings:  (N, D) — L2-normalised text features
    temperature:      learned scale parameter (typically ~0.07)
    
    Returns: scalar loss
    """
    N = image_embeddings.shape[0]
    
    # Pairwise cosine similarities (all normalised, so dot product = cosine sim)
    logits = image_embeddings @ text_embeddings.T  # (N, N)
    logits_scaled = logits / temperature
    
    # Ground-truth: diagonal pairs are matches (labels = 0, 1, 2, ..., N-1)
    labels = np.arange(N)
    
    def cross_entropy(logits_matrix, labels):
        # Numerically stable softmax + cross-entropy
        shifted = logits_matrix - logits_matrix.max(axis=1, keepdims=True)
        log_sum_exp = np.log(np.exp(shifted).sum(axis=1))
        correct_logits = shifted[np.arange(len(labels)), labels]
        return np.mean(log_sum_exp - correct_logits)
    
    # Symmetric: image→text and text→image
    loss_i2t = cross_entropy(logits_scaled, labels)        # image predicts text
    loss_t2i = cross_entropy(logits_scaled.T, labels)      # text predicts image
    return (loss_i2t + loss_t2i) / 2.0, logits

np.random.seed(42)
N, D = 4, 128   # batch of 4 image-text pairs, 128-dim embeddings

# Simulate embeddings: diagonal pairs should be similar
image_emb = np.random.randn(N, D)
text_emb  = np.random.randn(N, D)

# Make matching pairs more similar (add shared component)
for i in range(N):
    shared = np.random.randn(D) * 2
    image_emb[i] += shared
    text_emb[i]  += shared

# L2 normalise
image_emb /= np.linalg.norm(image_emb, axis=1, keepdims=True)
text_emb  /= np.linalg.norm(text_emb,  axis=1, keepdims=True)

loss, logit_matrix = clip_contrastive_loss(image_emb, text_emb)

print(f"CLIP contrastive loss: {loss:.4f}")
print()
print("Cosine similarity matrix (image i × text j):")
print("Diagonal = matching pairs (should be highest in each row)")
print(f"{'':>8}", end="")
for j in range(N):
    print(f"  text_{j}", end="")
print()
for i in range(N):
    print(f"image_{i}", end="")
    for j in range(N):
        marker = "*" if i == j else " "
        print(f"  {logit_matrix[i,j]:+.3f}{marker}", end="")
    print()

print()
print("* = matching pair. CLIP loss pushes these diagonal scores higher")
print("  and off-diagonal scores lower.")
```
